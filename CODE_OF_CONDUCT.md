# Contributor Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. Contributors and maintainers agree to uphold it in all project spaces (issues, pull requests, discussions) and when representing the project publicly.

In short: be respectful, assume good faith, welcome newcomers, and keep criticism about the work rather than the person. Harassment, discrimination, and personal attacks are not tolerated.

Because NukeSim deals with nuclear weapons effects, discussion should stay educational and non-operational. Do not post content aimed at targeting, weapon design, or real-world harm; such contributions will be removed.

## Reporting

Report unacceptable behavior privately to the maintainer via the contact on the [GitHub profile](https://github.com/lukifer23) or a private GitHub advisory. Reports are handled confidentially. Maintainers may take any action they deem appropriate, up to and including a ban from the project.

This code of conduct is adapted from the Contributor Covenant 2.1; see the link above for the full text and enforcement guidelines.
